# Contributing

This is a personal skills collection; external contributions are welcome as
issues or small PRs (typo fixes, translation improvements, pattern additions).

## Ground rules

- A skill is a single `SKILL.md` with standard frontmatter (`name`, `description`);
  triggers live in the description, workflow in the body.
- Keep skills self-contained: no absolute personal paths, no credentials,
  no employer-specific internals. Use placeholder domains (`*.corp.example`).
- Generated artifacts (logs, snapshots, summaries) never enter the repo.

## AI-assisted contributions

- Disclose AI assistance in the PR description.
- AI-generated comments must be high-signal: explain *why* / constraints /
  non-obvious behavior; comments that restate the code will be asked to rewrite.
- Every submitted change is reviewed for understanding — be ready to explain
  design choices, edge cases, and tests.
